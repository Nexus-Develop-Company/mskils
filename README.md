# 🚀 MSkills: Dopando tu OpenCode a nivel Dios

Arsenal de 56 Skills y 7 Agentes especializados para Full-Stack, Arquitectura, DBA, DevOps y Marketing. Evita código genérico.

## 📥 Instalación completa

```bash
npx mskills
```

## 📥 Instalación agéntica

- [Leer utilidades para el nombre de los agentes](./UTILIDADES.md)

```bash
npx mskills agent < NOMBRE_DEL_AGENTE >
```

## 📥 Instalación de skills

- [Leer utilidades para el nombre de los skills](./UTILIDADES.md)

```bash
npx mskills skill < NOMBRE_DEL_SKILL >
```

- **Para la desintalación mismos comandos agregando uninstall luego de mskills.**
  1. Puede borrar un solo agente.
  2. Puede borrar un solo skill siempre y cuando no este en uso por ningun agente
  3. Puede borrar todo de manera limpia y seguro.

- **Para más detalles ver la `Documetación` a continuación.**

## 🧠 Filosofía

- **No destructivo**: Prefijo `mskills-`, nunca sobrescribe archivos existentes.
- **Desinstalación inteligente**: Limpia completamente sin dejar rastros.
- **Instalacion multilugar**: Instala tus skills y agentes de manera global en tu ordenador o de manera local en un proyecto.
